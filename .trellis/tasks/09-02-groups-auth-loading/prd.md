# 分组展示、登录入口与首屏加载态

## Goal

首页支持按 `group` 筛选节点；导航栏未登录显示登录入口、已登录显示后台入口；首屏数据未到达时显示骨架加载态而不是空白。同时修掉延迟药丸不按适用节点过滤的缺陷。

## 背景

上传真实实例测试后收集到的四项，其中一项是缺陷。

真实实例的分组分布（12 节点 6 组）：

```
FreeCloud   4      华为云       2
Oracle      3      哇沃主机     1
Legendvps   1      DGN         1
```

一半的组只有 1 个节点，所以分区块显示会被三行组标题拉长页面。已定方案：筛选芯片。

## Requirements

### 1. 分组筛选

汇总条下方一行可点芯片，`全部` 打头，其后按节点数降序列出各组。芯片显示组名与节点数。

- 卡片视图与表格视图**共用同一个筛选状态**
- 表格额外把分组作为一列（默认展示，可在列开关里关掉）
- 选择持久化到 localStorage，键名沿用 `km-minimal-*` 前缀
- 所有节点都没有 `group` 值时整行芯片不渲染，不占位
- 选中的组被删空（节点全部移出）时回退到 `全部`，不能停在空列表

### 2. 登录 / 后台入口

导航栏右侧按访客身份二选一：

- 已登录 → 后台入口，跳 `/admin`
- 未登录 → 登录入口，同样跳 `/admin`（内置 UI 自行处理认证）
- 身份未知（接口不可用）→ 都不显示

`/login` 与 `/signin` 都只是被 SPA 兜底，没有独立路由，实测返回的是主题自身的 HTML；只有 `/admin` 是内置 UI（`web/public/public.go:198` 强制 default 主题）。所以两个入口都指向 `/admin`。

必须用 `<a>` 而非 `<Link>`：`/admin` 走客户端路由会被本主题的 `path="*"` 兜回首页。

### 3. 首屏加载态

首屏在元数据到达前显示骨架，而不是一行「加载中」文字。

- 卡片视图：若干张骨架卡，形状贴近真实卡片
- 表格视图：骨架行
- 汇总条：数值位骨架
- `prefers-reduced-motion` 下不做闪烁动画

### 4. 延迟药丸按适用节点过滤（缺陷修复）

`PingTask` 服务端结构里有 `clients: string[]`，是该任务适用的节点 uuid 列表（`database/models/pingTask.go:27` 的 `AppliesToClient` 依此判断）。当前类型定义漏了这个字段，卡片把全部任务无条件渲染，导致没配探测的节点也显示空药丸。

- 类型补 `clients`
- 卡片与表格都按 `clients.includes(uuid)` 过滤
- 任务没有 `clients` 字段或为空数组时，按「适用全部节点」处理（老版本服务端兼容）
- 过滤后为空则整个延迟区块不渲染

## 约束

沿用既有安全与兼容约束，不放宽：

- `theme_settings` 经未认证的 `GET /api/public` 全网可读，不放任何密钥
- 主题不得声明 `/admin` 与 `/terminal` 路由（链接过去可以）
- 页脚保留 `Powered by Komari Monitor.`
- 资源前缀固定 `/themes/{short}/dist/`
- `useSyncExternalStore` 快照必须引用稳定，否则 React #185

新增测试锚点保持 `km-` 前缀，纳入既有锚点约定。

## 验收标准

- [ ] `npm run build` exit 0
- [ ] `npm test` 全绿
- [ ] `node scripts/browser-check.mjs` 全绿
- [ ] `npm run package` 全绿
- [ ] 分组芯片：点击后卡片与表格都只剩该组节点；刷新后选择保留
- [ ] 无分组数据时芯片整行不出现
- [ ] 未登录显示登录入口、已登录显示后台入口，两种形态都在真实浏览器里验证过
- [ ] 首屏骨架：节流到慢速网络时能看到骨架而不是空白
- [ ] 延迟药丸只出现在 `clients` 含该节点的任务上；假服务端要有一个「没配探测」的节点覆盖这条
- [ ] 新增断言逐条验证过「改回错误实现时会失败」

## 非目标

- 不做分区块或可折叠分组（已评估：单节点组过多，页面会被标题拉长）
- 不在主题内实现登录表单，认证一律交给内置 UI
- 不改站点 logo 与 favicon 的来源：Komari 只提供自定义 favicon（运营者放 `./data/favicon.ico`，服务端在 `/favicon.ico` 优先返回），没有下发 logo 的接口，导航栏图标保持本主题自带
